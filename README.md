## 👨🏽‍💻 About Me

I'm a **Senior Platform & Infrastructure Engineer** focused on designing, automating, securing, and operating cloud infrastructure.

My work sits at the intersection of **Cloud Engineering, Platform Engineering, DevOps, and DevSecOps**. I enjoy turning manual infrastructure and deployment processes into repeatable, automated, and maintainable systems.

My primary cloud platform is AWS, and I work with Infrastructure as Code, containerisation, CI/CD, Kubernetes, security automation, and observability.

- ☁️ **Cloud:** AWS, Azure, GCP, and DigitalOcean.
- 🏗️ **Infrastructure as Code:** Terraform and Ansible.
- 📦 **Containers & Orchestration:** Docker, Docker Compose, Kubernetes, Amazon ECS, and ECR.
- ⚙️ **CI/CD & Automation:** GitHub Actions and Jenkins.
- 🔐 **DevSecOps:** Infrastructure security, container image scanning, SAST/DAST, and security automation.
- 📊 **Observability:** Prometheus, Grafana, Loki, and AWS CloudWatch.
- 🐧 **Systems & Scripting:** Linux, Bash, and Python.
- 🎓 **Certification:** Kubernetes and Cloud Native Associate (KCNA).

I'm particularly interested in building reliable cloud platforms, improving developer workflows, and embedding security and observability into the software delivery lifecycle.
